# dtCalc

**Native OSF/Motif 2.3 RPN, Algebraic, Scientific, RF & 64-Bit Programmer Workstation Calculator for CDE**

`dtCalc` (`cde-calc`) brings an HP-48 / HP-16C / vintage bench calculator to the Common Desktop Environment (`Utilities` subpanel). Features a custom-rendered **Vacuum Fluorescent Display (VFD)** with switchable **Cyan-Green VFD**, **HP Red LED**, **Amber Plasma**, and **Olive LCD** themes, full **4-level RPN stack (`T, Z, Y, X`) + Algebraic** modes, **RF engineering keys (`f↔λ`, `dBm↔W`, `dBV`, `LC Res`)**, clickable **64-bit LED binary bit-toggle switches** (`HEX / DEC / OCT / BIN`), and a toggleable **`#FFF7E9` greenbar paper-tape roll**.

## Build & Install

```bash
cd dtCalc && ./install.sh
```
