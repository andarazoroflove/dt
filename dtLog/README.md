# dtLog

**Vintage Amateur Radio QSO & SWL Station Logbook for CDE — Analog Great-Circle Beam Compass, Offline DXCC Prefix Resolver, ADIF 3.1 Engine & `dtRadio` Bridge**

`dtLog` brings a classic 1980s/1990s shack console and tractor-feed greenbar station logbook to the Common Desktop Environment (`Radio Apps` subpanel). Pre-configured out of the box for **`W1AW` (`FN31pr` — Newington, Connecticut)** and editable for any callsign/grid, it features a glowing **VFD UTC/Local Shack Clock & Telemetry Matrix**, a warm backlit **360° Analog Rotor / Great-Circle Azimuth Beam Compass** (short-path + long-path needles with live distance in `km`/`mi`), an offline **265+ Entity ARRL DXCC & US/VE Call-Area Resolver** with instant dupe detection, one-click **`[⚡ GRAB FROM dtRadio]`** frequency/mode/station capture, **WSJT-X & ADIF 3.1 (`.adi`)** import/export, and a **Vintage QSL Card Generator** (`.PNG` & ASCII).

## Install

```bash
cd dtLog && ./install.sh
```
