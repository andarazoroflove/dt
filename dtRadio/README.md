# dtRadio

**Vintage Communications Receiver for CDE — HF/Shortwave (`0–30 MHz` KiwiSDR), Linked Ham Repeaters, NOAA Weather, FEMA/Emergency, Space Audio & RTL-SDR**

`dtRadio` brings a tabletop 1980s/1990s HF communications receiver faceplate to the Common Desktop Environment (`Radio Apps` subpanel). Features a live ballistic analog **S-Meter**, glowing **Vacuum Fluorescent Display (VFD)** + vernier slide-rule scale, weighted **VFO flywheel**, real-time GStreamer **IF Bandpass / Clarifier / Squelch / Noise Blanker / Tone** DSP knobs, press-and-hold **Memory Bank (`M01`–`M12`)**, direct **Orange Emergency/FEMA** and **Blue NOAA Weather** buttons, and built-in **RTL-SDR (`rtl_fm`)** USB dongle support.

## Install

```bash
cd dtRadio && ./install.sh
```
